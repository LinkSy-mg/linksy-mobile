# Screenshots

Linksy for Android 0.3.1, for the website. Taken on 2026-11-02 from a clean install
(phone named "Pixel 9") with two paired computers: **Studio Desktop** (a Linux desktop
with a picture, its battery and music playing) and a **ThinkPad** (not nearby), plus
**Living Room PC**, nearby but not paired. 1080 × 2400 PNG; `music-notification.png`
is a 1080 × 506 crop. Light unless the name says `-dark`.
